# MesaAyuda

Sistema web de mesa de ayuda desarrollado con ASP.NET Web Forms, C#, SQL Server, AJAX, jQuery y Bootstrap.

## Solucion

- `MesaAyuda.Frontend`: interfaz Web Forms, WebMethods, sesiones y handler de evidencias.
- `MesaAyuda.Backend`: modelos, seguridad SHA256, logica de negocio y acceso a datos.
- `Database`: instalacion, procedimientos almacenados, funcion SHA256 y trigger de auditoria.

La aplicacion esta configurada para SQL Server en `.\MSSQLSERVER2025` y la base `MesaAyudaDb`.

Consulte `INSTRUCCIONES.md` para instalar la base y ejecutar la solucion.
